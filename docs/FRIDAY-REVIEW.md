# Friday Review Build

## Purpose
This version is a review prototype, not a production deployment. It is intended to demonstrate the complete product direction and the guest/admin experience before the next engineering phase.

## Demonstrable flows
1. Open the hotel homepage.
2. Explore Stay, Menu, Events, Gallery, About, Location and Contact.
3. Open Book / Enquire and submit the guest form to see the prototype confirmation state.
4. Open Admin preview from the footer and walk through the information architecture for Rooms, Menu, Events, Gallery, Bookings, Enquiries and Content.

## Review talking points
- Guests do not need permanent accounts.
- Booking is an enquiry/request until hotel staff confirms it.
- Hotel content is intended to become dynamic through the future admin system.
- The project avoids fabricated reviews, room prices, events and customer data.
- The visual system is built around real Green Park photography, strong typography and restrained motion.
- Production security, PostgreSQL persistence, API services and image processing remain documented as the next phase rather than being falsely shown as complete.
